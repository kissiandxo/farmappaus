# App Store screenshots

Ten real screenshots of Farm Direct 1.0, taken on an iPhone 6.9-inch simulator by `.github/workflows/screenshots.yml`. Each is 1320 x 2868, the size App Store Connect asks for.

| File | Screen |
|---|---|
| `01-explore.png` | Explore: 151 places, search, location and filters |
| `02-explore-meat.png` | Explore with the Meat filter on: 86 places |
| `08-place-butcher.png` | Feather and Bone in Marrickville: shop hours, directions and contact options |
| `03-place-farm-shop.png` | A farm shop's page: hours, directions, call, produce |
| `04-place-market.png` | A weekly farmers' market's page |
| `05-saved.png` | Saved places |
| `06-map.png` | The map, with a pin for every place |
| `07-map-dark.png` | The same map in dark appearance |
| `09-welcome.png` | Native Continue with Apple and guest access |
| `10-tour.png` | The live location control highlighted in the onboarding walkthrough |

Explore, Explore with Meat selected, and the butcher page were captured on 25 November 2026 in [simulator run 45593955101](https://github.com/kissiandxo/farmappaus/actions/runs/45593955101). The farm shop, market, saved list and map captures come from the November 13 simulator runs. The first three store images use these original Explore, butcher and market frames with editorial captions. They are named `store-01-explore.png`, `store-02-butcher.png` and `store-03-market.png`. The rest of the store gallery shows the farm shop, saved list, welcome and location walkthrough. The last two were captured from the backend-free release on iPhone 17 Pro Max running iOS 26.5. [Native interaction run](https://github.com/kissiandxo/farmappaus/actions/runs/45609367849)

The places shown are real listings from public sources and are marked in the app as not confirmed by their owners. Retake the screenshots if the listings or the design change.
