# Farm Direct 1.0 — polish build plan

_Generated from the audit (browse, map, place, shell, a11y, review, data) and three feature lenses (shopper, launch, delight). Plan date: 13 Nov 2026._

## Summary

Tonight's 1.0 build has eight shopper features and fixes every high and medium audit finding, apart from the deferred items listed with reasons. The features are: search on Explore; a type-of-place filter; a 'When can you go?' filter (Any time, Open now, This weekend); sharing a place; places nearby on each place page; honest location set-up; compact, accurate opening hours; and a Saved tab that never loses saves and lets you remove a place without opening it. Every feature reuses tested domain logic (searchFarms, openStatus, haversineKm, directionsUrl). None adds a native module or package, and none states anything about a place beyond the research files. Six engineers work in parallel on disjoint files: (1) listings data, (2) domain logic and search state, (3) the Explore UI, (4) the Map, (5) the place page and Saved, (6) the app shell, About, privacy, theme, primitives and release configuration. Where two packages meet, both name the same exported function, prop or type. A final engineer integrates the work, removes dead code and rewrites the docs and App Store copy so they match what ships. The five ads are a later workflow step and are not part of this plan.

## Chosen features

1. Search places by name, town, postcode or produce (native search bar on Explore)
2. Type-of-place filter (Farmers' markets, Farm shops, Farm-gate stalls, Farms)
3. 'When can you go?' filter: Any time / Open now / This weekend, with this weekend's published times on each card
4. Share a place (place page header and map place card) through the iOS share sheet
5. Nearby places on the place page (up to 3 within 60 km of that place)
6. Honest location set-up: 'Use my location' on the welcome screen, plus an actionable default-location prompt on Explore and Map instead of silent Sydney distances
7. Compact, honest opening hours: merged day runs, the schedule note first for monthly or seasonal places, and 'Opens today/tomorrow' status wording
8. Saved that never loses a save and lets you remove a place without opening it

## Rules for every engineer

- Packages run in parallel in one working tree. Edit only the files your package owns. If you need a change in another package's file, use the interface named in both packages' tasks.
- Expo SDK 58: read the versioned docs (https://docs.expo.dev/versions/v58.0.0/) before touching any Expo or React Native API. Add no packages and no native modules.
- Follow docs/DESIGN.md: tokens from src/theme.ts, primitives from src/components/ui, Australian English.
- HARD FACT RULE: nothing about a real place beyond docs/research/listings/*.json.
- Finish with `npx tsc --noEmit`, `npx expo lint` and `npx jest`.
